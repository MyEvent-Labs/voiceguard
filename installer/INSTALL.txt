MyEvent Labs VoiceGuard v0.0.1 Alpha - Windows x64
==================================================

This installer places:

  Standalone  C:\Program Files\MyEvent Labs\VoiceGuard\MyEvent Labs VoiceGuard.exe
  VST3        C:\Program Files\Common Files\VST3\MyEvent Labs VoiceGuard.vst3

Both need administrator rights to install, because the VST3 format requires the
shared Common Files\VST3 folder.

Using it in a host
------------------
1. Install as above.
2. Rescan plugins in your host (REAPER, Ableton Live, Studio One, etc.).
3. Insert "MyEvent Labs VoiceGuard" on a speech channel.
4. Default workflow: insert -> AUTO -> mix.

Uninstalling
------------
Settings > Apps > Installed apps > MyEvent Labs VoiceGuard > Uninstall, or run
the "Uninstall MyEvent Labs VoiceGuard" shortcut in the Start Menu group.

The uninstaller removes the standalone app and the VST3 bundle. It does not
touch your host project files.

show-critical use. Windows SmartScreen may warn because the build is not
